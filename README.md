## Installation

You can install the package via Composer:

```bash
composer require satnam-singh/sbi-epay
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="sbi-epay"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="sbi-epay-config"
```

### Publishing and Running the Migrations

```bash
php artisan vendor:publish --tag="sbi-epay-migrations"
php artisan migrate
```

### Publishing the Views

```bash
php artisan vendor:publish --tag="sbi-epay-views"
```

### Publishing the Translations

```bash
php artisan vendor:publish --tag="sbi-epay-lang"
```

### Publishing the Public Assets

```bash
php artisan vendor:publish --tag="sbi-epay-assets"
```
